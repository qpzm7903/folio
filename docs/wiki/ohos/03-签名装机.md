# 鸿蒙适配 Wiki · 03 签名与装机 (Mate 80 真机)

> Folio L20 里程碑③。结论先行: **纯血鸿蒙零售机 (HarmonyOS 6 / Mate 80)
> 必须用华为 AGC 调试证书, OpenHarmony 自签链装不上。** 但整条
> hap-sign-tool 签名 + hdc 装机工装两条路通用, 仅证书来源不同。

## 1. 先证伪: OpenHarmony 自签为什么不行 (实测)

OpenHarmony SDK `toolchains/lib/` 自带一整套签名物料:
`hap-sign-tool.jar` + `OpenHarmony.p12` (含 app/profile/CA 全部私钥) +
`OpenHarmonyProfileDebug.pem` + `UnsgnedDebugProfileTemplate.json`。
用它能**全程离线**签出一个 hap:

```
sign-profile      success   # profile 签名 OK
generate-app-cert success   # 用 p12 里的 Application CA 私钥现签 app 证书链
sign-app          success   # "Sign Hap success!"
```

(注意: 这个 SDK 的 p12 里每张证书都是**自签密钥对**, 不含 "Release←CA"
生产链, 所以 app 证书链不能直接 export, 要用 `generate-app-cert -outForm
certChain` 拿 CA 私钥现签 —— 这一步卡了最久。)

签出来的 hap 装机直接被拒:

```
$ hdc install -r entry-default-signed.hap
error: failed to install bundle. code:9568257 error: fail to verify pkcs7 file.

$ hdc shell param set persist.bms.ohCert.verify true
Set parameter persist.bms.ohCert.verify true fail! errNum is:1001!
```

**两条铁证**:
1. `fail to verify pkcs7 file` — 设备校验签名链时, OpenHarmony Root CA
   不在华为信任根里, 拒签。
2. `errNum 1001` — 想关掉证书校验 (OpenHarmony 开发板/模拟器上能用的
   `persist.bms.ohCert.verify` 开关) 被**零售机直接拒绝设置**。这正是
   纯血鸿蒙的安全模型: 零售设备不允许降级签名校验。

→ 自用调试也绕不开华为账号。OpenHarmony 自签只适用于 OpenHarmony
开发板 / 模拟器, 不适用于零售 HarmonyOS NEXT 设备。

## 2. 正路: AGC 调试证书 (手动, 不装 DevEco)

需要: 华为开发者账号 (个人实名, 免费)。整条命令行工装复用, 只把
"OpenHarmony 自带证书" 换成 "AGC 签发的 .cer + .p7b"。

### 2.1 本地预生成 (已完成, 见 ohos/.signing/agc/)

```bash
# app 签名密钥对 (ECC P-256) → 自建 p12
hap-sign-tool generate-keypair -keyAlias folio-ohos-key -keyAlg ECC \
  -keySize NIST-P-256 -keyPwd *** -keystoreFile folio.p12 -keystorePwd ***
# CSR (上传 AGC 换证书)
hap-sign-tool generate-csr -keyAlias folio-ohos-key -keyPwd *** \
  -subject "C=CN,O=folio,OU=folio,CN=Folio Debug" -signAlg SHA256withECDSA \
  -keystoreFile folio.p12 -keystorePwd *** -outFile folio.csr
```

`folio.p12` (私钥) 永不离开本机、不入库; 只有 `folio.csr` 上传 AGC。

### 2.2 AGC 网页三步 (需账号登录)

设备 UDID (Mate 80): `hdc shell bm get --udid` 取, 注册时用。

1. **调试证书**: AGC → 用户与访问 → 证书管理 → 新增调试证书 → 上传
   `folio.csr` → 下载 `folio.cer`。
2. **注册调试设备**: AGC → 用户与访问 → 设备管理 → 添加设备 → 类型选
   手机 → 填 Mate 80 的 UDID。
3. **调试 Profile**: AGC → 我的项目 → 新建 HarmonyOS 应用 (包名
   `app.folio.ohos`) → 管理证书与 Profile → 添加调试 Profile → 勾选
   上面的调试证书 + 调试设备 → 下载 `folio.p7b`。

### 2.3 本地签名装机 (复用工装)

把 `folio.cer` / `folio.p7b` 放进 `ohos/.signing/agc/`, 然后:

```bash
hap-sign-tool sign-app -mode localSign -keyAlias folio-ohos-key -keyPwd *** \
  -appCertFile folio.cer -profileFile folio.p7b \
  -inFile entry-default-unsigned.hap -signAlg SHA256withECDSA \
  -keystoreFile folio.p12 -keystorePwd *** -outFile entry-default-signed.hap
hdc install -r entry-default-signed.hap
```

(`tool/ohos/sign_and_install.sh` 默认走 OpenHarmony 自签做连通性自测;
AGC 模式见脚本内 `SIGN_MODE=agc` 分支。)

## 3. 备选: DevEco 自动签名

若嫌 AGC 网页三步繁琐, DevEco Studio "Automatically generate signature"
一键完成 2.1–2.3 (登录账号即可)。代价是装 DevEco (~数 GB)。本项目坚持
命令行路线, 仅在 AGC 手动流程受阻时作兜底。
